# 기사 프로젝트 노트

기사 프로젝트를 정리하는 간단한 노트 페이지입니다. HTML 파일 하나로 만들어져 있어서 설치 없이 바로 열어 쓸 수 있습니다.

## 구성

- **프로젝트 한 줄**: 프로젝트를 한 줄로 적는 칸
- **주제**: 대주제를 적는 칸
- **할 일 체크리스트**: 5개의 할 일을 적고 체크하는 칸
- **날짜별 기록**: 날짜마다 한 줄씩 남기는 타임라인

## 사용 방법

1. `project-note.html` 파일을 내려받습니다.
2. 브라우저(크롬, 사파리 등)로 파일을 엽니다.
3. 칸을 눌러 바로 입력합니다. 내용은 브라우저에 자동 저장됩니다.

## 참고

- 휴대폰 화면에서도 보기 좋게 만들었습니다.
- 입력한 내용은 사용 중인 기기의 브라우저에만 저장됩니다. 다른 기기와는 공유되지 않습니다.
- 전화번호나 주소 같은 개인정보 칸은 없습니다.
